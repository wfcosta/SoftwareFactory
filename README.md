# Generic Software Factory (GSF)

Framework agnóstico para orquestração de agentes.

## Como integrar seu Harness
1. Aponte seu harness para este diretório.
2. Configure o `config.json` para que o harness entenda os caminhos.
3. Carregue `GSF_FACTORY.md` como instrução principal (System Prompt).
4. Utilize os scripts em `skills/` para automatizar tarefas comuns.
