# Playbook: Performance Issue

**Objective:** Trace measured slowness and improve performance against a baseline.

## Steps
1. **Baseline Measurement:** Capture reliable performance metrics and baseline profile.
2. **Bottleneck Identification:** Trace CPU, memory, or I/O hot spots using tracing tools.
3. **Targeted Optimization:** Apply minimal optimizations based on root cause.
4. **Validation:** Re-measure against baseline and explain the number.
