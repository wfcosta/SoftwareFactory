# Playbook: Investigation

**Objective:** Answer a read-only technical question or diagnostic investigation with absolute evidence.

## Steps
1. **Scope & Hypotheses:** Define the specific question or symptoms. List initial hypotheses.
2. **Evidence Gathering:** Use codebase search (`grep`, `read`) and log analysis to inspect relevant modules without guessing.
3. **Cross-Validation:** Check callers, types, and historical context to ensure findings are correct.
4. **Synthesis:** Produce an evidence-backed factual answer citing exact file paths, line numbers, and runtime observations.
