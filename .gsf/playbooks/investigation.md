# Playbook: Investigation

**Objective:** Answer a read-only technical question or diagnostic investigation with absolute evidence.

## Operational Steps
1. **Scope & Hypotheses Definition:**
   - Clearly formulate the question or anomaly.
   - List initial working hypotheses.
2. **Evidence Gathering:**
   - Search codebase and logs using rigorous search tools.
   - Gather empirical facts (callers, types, data schemas, historical context).
3. **Cross-Validation:**
   - Check all potential edge cases and conflicting assumptions.
4. **Synthesis:**
   - Produce a concise, evidence-backed conclusion citing exact file paths, line numbers, and empirical observations.
