# Playbooks: Forensics & Features & Prototypes

- **runtime-forensics.md:** Diagnose live symptoms (memory leaks, CPU spins) from instrumentation.
- **trace-forensics.md:** Diagnose profiling artifacts (CPU profiles, heap snapshots).
- **feature.md:** Build new or changed behavior from named data shapes with end-to-end verification.
- **prototype.md:** Throwaway sketch to make design/behavioral decisions cheaply.
- **visual-parity.md:** Pixel-exact UI equivalence between implementations.
- **authoring-a-skill.md:** Writing or editing SKILL.md specifications.
- **eval.md:** Test how skill or prompt changes affect agent behavior blinded.
- **babysit.md:** Drive PR or stack to merge-ready: conflicts, review threads, CI.
- **shipping.md:** Independently verify green stack, land contiguous verified run bottom-up.
- **autonomous-run.md:** Drive long tasks to completion without stopping.
- **orchestrate.md:** Multi-day coordinator for stacked PRs and agent fleets.
- **autopilot-full.md:** Run independent PRs to merged with one owner per PR.
- **autopilot-stack.md:** Build and verify stacked PRs for operator review.
- **session-pickup.md:** Resume prior agent's in-flight work.
- **pause-safely.md:** Suspend in-flight work cleanly for later resumption.
- **multi-phase-plan.md:** Work spanning phases or stacked PRs.
- **worktree-cleanup.md:** Reclaim disk by pruning merged worktrees and simulators.
- **opening-a-pr.md:** Open ready PR from small ordered commits with conventional commits title.
