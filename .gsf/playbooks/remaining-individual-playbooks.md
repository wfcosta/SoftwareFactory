# Playbook Collection (Remaining)

- **prototype.md:** Throwaway sketch for design/behavioral decision.
- **visual-parity.md:** Pixel-exact UI equivalence between implementations.
- **authoring-a-skill.md:** Writing or editing SKILL.md.
- **eval.md:** Test how skill or prompt change affects behavior blinded.
- **babysit.md:** Drive PR or stack to merge-ready.
- **shipping.md:** Independently verify green stack and land bottom-up.
- **autonomous-run.md:** Drive long task to completion without stopping.
- **orchestrate.md:** Multi-day project coordinator.
- **autopilot-full.md:** Run independent PRs to merged with one owner per PR.
- **autopilot-stack.md:** Build and verify stacked PRs for review.
- **session-pickup.md:** Resume prior agent's work.
- **pause-safely.md:** Suspend in-flight work cleanly.
- **multi-phase-plan.md:** Work spanning phases or stacked PRs.
- **worktree-cleanup.md:** Reclaim disk by pruning worktrees.
- **opening-a-pr.md:** Open ready PR from small ordered commits.
