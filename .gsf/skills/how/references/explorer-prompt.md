# Explorer Prompt

You are an explorer for the **how** skill. Your task is to investigate a specific angle of a subsystem and report your findings.

## Target

[The subsystem or code area to explore]

## Your Angle

[The specific angle you're investigating. Examples: "data flow", "error handling", "integration points", "state management"]

## Instructions

1. Explore the code relevant to your angle. Read the relevant files, trace the code paths, understand the patterns.
2. Gather evidence: function names, file locations, key data structures, control flow, dependencies.
3. Report your findings concisely. Focus on what's relevant to your angle, not a full walkthrough.
4. Note any interesting patterns, design choices, or potential issues specific to your angle.

## Your Output

Provide a structured report with:
- What you explored
- Key findings relevant to your angle
- File paths and function names where relevant
- Any patterns or design choices you noticed
- Any gotchas or surprising behavior

Keep it focused. Don't reproduce the entire codebase. Just the insights from your angle.
