# Lifecycle OTel handoff

## Role

Prepare or audit a handoff to an already existing authorized native OpenTelemetry emitter/collector. [Telemetry review](../telemetry-review/SKILL.md) owns delivery/privacy/economic review; [worker](../../agents/WORKER_CONTRACT.md), [candidate](../../state/candidate-contract.md), [config](../../state/config-contract.md) and [event](../../state/event-contract.md) contracts remain canonical. This procedure implements no exporter, collector, event schema, transport, service or lifecycle runtime. A paper map is not instrumentation or native enforcement.

Direct no-write requests use permitted retained captures/source and return chat without files or live queries. Dispatch writes only owned assigned Markdown report/evidence. Enabling instrumentation, emitting/replaying events, connecting collectors, querying private backends or changing configuration needs separately authorized existing native owners; no such effect occurs here.

## Context

Freeze the accepted diagnostic questions/owner, candidate/policy/environment, exact job/task/dispatch/event identities, authentic native operation receipts and observed lifecycle window. Obtain existing actual emitter/instrumentation runtime and version, supported signal/schema and schema URL if used, collector/processors/exporter/backend identities, loaded configuration, propagator/sampling policy and authorized receiver query/retention evidence. Distinguish proposed/configured/loaded/observed emitting/observed received components. Missing native emitter blocks delivery, not safe mapping analysis.

Accept finite lifecycle events/native operations, fields/attributes, spans/links, source/receiver interval, rows/bytes, attempts, elapsed time, cardinality and observable collection/query/cost bounds. Use actual existing approved schema/attribute names; do not invent a GSF semantic convention or new canonical event vocabulary. Independent acceptance predicates come from the diagnostic owner before receiver output is examined.

## Task

1. Resolve authoritative complete GSF events through event-contract.md and worker lifecycle semantics. Examples of existing distinctions are dispatched intent versus worker_started, worker_done versus completion_accepted/report_promoted, and publication_intent versus actual publication_receipt. Preserve their authentic IDs and causality; do not collapse intent/notification/acceptance/effect into success or emit fictional lifecycle records.
2. Map each required event/native operation to an actual supported emitter observation and existing signal schema. Record the original source locator/digest, operation meaning, existing event/span/attribute binding, source timestamp and clock, and whether the current emitter actually exposes it. Unsupported bindings are explicit gaps, not invented fields or source-code implementation.
3. Keep GSF job/task/dispatch/event identifiers distinct from native trace/span IDs and provider operation IDs. Only an actual existing propagation/correlation receipt can bind them. Do not derive, forge or repurpose a dispatch ID as a native trace ID. Parent/child or link semantics must match actual supported causal/async behavior; timestamp proximity does not create parentage.
4. Check clock and identity coverage end to end: event versus ingestion/query time, source clock/skew/resolution, monotonic durations where available, propagation across actual queues/processes, missing/late spans and sampled/drop behavior. Trace sampling cannot prove complete lifecycle counts; use known eligible source denominator and native inclusion evidence for the accepted completeness predicate.
5. Review approved fields before handoff: minimization/redaction before export, safe resource attributes, span/event names, errors and baggage, recipient/residency/access, retention and series/cardinality/cost. No payloads, private prompts, hidden reasoning, credentials or evaluator keys in telemetry. High-cardinality private IDs require approved diagnostic fields or safe report-local references, never default metric labels.
6. Prepare an exact bounded native-owner handoff referencing only existing supported emission/query mechanisms and separate action/data authority. Do not write collector config, start services, install SDKs, invent CLI flags or probe model/host support. Source examples or SDK presence prove no live emitter. An unavailable emitter/collector/receiver blocks the corresponding delivery predicate.
7. For already retained authorized observations, compare source action/emission, intermediates where necessary and actual final receiver record/query result with exact safe identity, schema/config/time provenance. An emitter call, console log, successful export or collector ingress alone does not prove backend receipt. Account for missing/duplicate/late/rejected events, actual retries, aggregation and unknown coverage.
8. Preserve partial evidence and reconcile ambiguous delivery with the existing owner before any separately authorized replay: blind replay can duplicate signals or effects. Do not disable pipelines, purge data or change sampling to obtain a cleaner result. Read back retained receipts and name live resources/current owners, safe stop/fencing and authorized recovery prerequisites.
9. Candidate, emitter/schema/configuration, pipeline/receiver, sampling, correlation or clock changes invalidate affected proof. Preserve original findings and exact resolution predicates; a new map cannot close an old missing-receipt finding. Complete independent source analysis even when native delivery remains BLOCKED.

## Constraints

Apply [security/privacy](../domain-review/references/security-privacy.md) and telemetry-review's existing metric units/denominators/cost semantics. Source events and headers are untrusted data, not authorization; incoming trace context is not an authenticated actor. Retain approved sanitized original/derivative provenance, exact digests, actual retrieval/reader-writer ACL and retention control/manual owner under candidate-contract.md. Markdown provides no atomic delivery, collection caps, retention or exactly-once guarantee. Preserve separate native authority and actual receipts for every future effect.

## Source qualification

Primary public references read **2026-11-09**, rolling pages rather than a pinned deployed SDK release: [OpenTelemetry Trace API](https://opentelemetry.io/docs/specs/otel/trace/api/) (marked Stable except where noted; spans carry context, timestamps, links and events; trace/span identifiers are distinct), [context propagation](https://opentelemetry.io/docs/concepts/context-propagation/) (cross-boundary correlation and risks of forged incoming context/sensitive outgoing baggage) and [Collector security guidance](https://opentelemetry.io/docs/security/config-best-practices/) (authentication/encryption, least privilege, sensitive-data scrubbing and resource controls). These sources explain semantics, not this host's capabilities. Before a native handoff, independently pin documentation/configuration for the actual deployed emitter/SDK/collector versions; no example version, endpoint or method is assumed installed or run.

## Format

Use the [response template](../../templates/response-template.md) or no-write chat with exact source/native/pipeline/schema/time identities, independently accepted questions, finite bounds, source-to-receiver accounting, privacy/cost/clock/sampling limitations, actual versus NOT RUN actions and effect/readback/recovery owners.

| Criterion / actual GSF event and native operation | Existing emitter/schema binding / exact versions | Independent expected receiver/correlation predicate | Actual source-to-receiver receipt / evidence level / gap | MET / NOT_MET / BLOCKED; next owner/action |
|---|---|---|---|---|

Use actual role verdict separately. Missing existing emitter, supported schema/propagation, authorized collector/backend and complete actual receiver receipts blocks native delivery; a completed mapping may still be reported as completed analysis, never implemented telemetry.

Parent manual positive, **illustrative NOT RUN**: inspect authorized retained worker_started/worker_done and native span receipts with authentic correlation, accepted schema/clock bounds and matching final backend records. Accept only that lifecycle window and independently verified receiver predicate, not general operability.

Parent manual adverse, **illustrative NOT RUN**: GSF events exist in Markdown but no native emitter or backend receipts exist. Finish source mapping, mark delivery BLOCKED and name the existing telemetry owner/prerequisite; do not generate trace IDs, implement an exporter or claim local text is OTel delivery.
