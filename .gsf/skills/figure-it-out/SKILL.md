# Figure It Out

Solve a problem autonomously. The agent must figure out the solution through investigation, experimentation, and reasoning.

## When to Use

- You don't know the solution and need the agent to find it
- Complex investigation required
- Debugging an unknown issue
- Researching a new domain

## Process

1. **Understand the problem**: What needs to be solved?
2. **Investigate**: Gather information through:
   - Reading code/docs
   - Running commands
   - Searching the codebase
   - Web research if needed
3. **Form hypotheses**: What are possible solutions?
4. **Test hypotheses**: Try solutions and verify
5. **Iterate**: Refine based on what works and what doesn't
6. **Converge**: Arrive at a working solution
7. **Verify**: Confirm the solution actually solves the problem

## Guidelines

- Be thorough in investigation
- Don't guess—prove with evidence
- Document your reasoning
- If stuck, try different approaches
- Ask for clarification only if truly blocked

## Output

The solution with:
- What the problem was
- How you investigated it
- What you tried
- What worked
- Verification that it's solved
