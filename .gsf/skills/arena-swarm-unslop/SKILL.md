# Skill: Arena, Swarm, Unslop, Technical Writing

- **Arena:** N parallel attempts at the same problem, extracting the best parts.
- **Swarm:** N parallel workers across different slices or races, yielding an aggregated report.
- **Unslop:** Remove AI writing tells and tighten text.
- **Technical Writing:** Layered documentation standard (Diátaxis + Google Style).
