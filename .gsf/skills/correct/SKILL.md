# Correct

Fix a specific, targeted code issue or error. This is different from a general bug fix—it's for when you know exactly what needs to be corrected.

## When to Use

- You know the exact fix needed
- The issue is isolated and clear
- No investigation required
- Direct correction is appropriate

## Process

1. **Identify the issue**: What exactly needs to be fixed?
2. **Locate the code**: Where is the issue in the codebase?
3. **Apply the fix**: Make the minimal change to correct it
4. **Verify**: Confirm the fix works (run tests, check behavior)
5. **Check for side effects**: Did the fix break anything else?

## Output

The corrected code with:
- What was changed
- Why it was changed
- Verification that it works
