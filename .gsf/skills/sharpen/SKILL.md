# Sharpen

Refine a prompt to be deeper and more effective without making it longer. Focus on precision, context, and clarity rather than volume.

## When to Use

- Before sending a complex prompt
- When a prompt feels vague or scattered
- When you want better results from an agent
- When refining a prompt for reuse

## Process

1. **Identify the core question**: What's the real ask? Strip away noise.
2. **Add necessary context**: What background is essential? Not everything, just what matters.
3. **Specify constraints**: What are the boundaries? What shouldn't be done?
4. **Define success criteria**: What does a good answer look like?
5. **Remove redundancy**: Eliminate repeated information
6. **Clarify ambiguity**: Replace vague terms with specifics
7. **Order logically**: Put context first, then question, then constraints

## Principles

- Deeper > Bigger: A focused 50-word prompt beats a vague 500-word prompt
- Essential > Comprehensive: Include what matters, not everything
- Specific > General: "Fix the memory leak in the cache" > "Fix performance issues"
- Constraints > Open-ended: "Within 100 lines, without external deps" > "Write clean code"

## Output

The sharpened prompt with:
- Original prompt (for comparison)
- What changed and why
- The refined prompt
