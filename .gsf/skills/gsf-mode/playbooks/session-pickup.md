### Session Pickup

**You own the continuity.** Resume or take over a prior agent's in-flight work. This is for when work spans sessions or agents.

1. **Locate the context.** Find the prior session's evidence:
   - Job directory in `.gsf/jobs/`
   - Project plan or todo list
   - PR with work in progress
   - Decision trail (show-me-your-work)
   - Any written artifacts (spec.md, investigation reports)
2. **Understand the state.** Read through the evidence to understand:
   - What was the goal?
   - What phase is the work in?
   - What's been completed?
   - What's in progress?
   - What's blocked?
   - What are the open decisions?
3. **Rehydrate the mental model.** Run **how** over the affected subsystem if the context is stale or unclear. Ensure you understand the current state.
4. **Pick up where the prior agent left off.** Continue from the last completed step. Don't redo work that's already done unless verification shows it's wrong.
5. **Maintain continuity.** Use the same job directory, append to the same inbox, update the same project plan. Don't fragment the evidence.
6. **Report the pickup.** State what you found, where you're resuming, and what you'll do next.

**Reply:** prior context found, current state assessment, resumption point, next steps.
