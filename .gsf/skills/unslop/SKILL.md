# Unslop

Remove AI writing tells and tighten text. AI-generated text often has characteristic patterns that make it sound robotic or inauthentic. This skill removes those patterns and produces natural, human-like prose.

## AI Writing Tells to Remove

### Wordiness
- "In order to" → "to"
- "Due to the fact that" → "because"
- "At this point in time" → "now"
- "For the purpose of" → "to"
- "In the event that" → "if"
- "It is important to note that" → delete
- "It should be mentioned that" → delete

### Hedging
- "I would suggest that" → "suggest"
- "It might be worth considering" → "consider"
- "One could argue that" → delete or state directly
- "It appears that" → delete or state directly
- "Seems to be" → "is" (if confident)

### Passive Voice
- "It was decided that" → "We decided" or active voice
- "Mistakes were made" → "We made mistakes"
- "The code was modified" → "We modified the code" or "The code changed"

### Filler Phrases
- "Basically," "essentially," "fundamentally" → delete (unless truly necessary)
- "As mentioned above," "as previously stated" → delete (the reader remembers)
- "In conclusion," "to summarize" → delete (the conclusion is obvious)

### Over-Explanation
- Explaining things the reader already knows
- Defining common terms
- Stating the obvious
- Walking through simple steps in excruciating detail

### Robotic Phrasing
- "The implementation of the feature involves..." → "To implement..."
- "The utilization of..." → "Using..."
- "The execution of..." → "Running..."
- "The performance of..." → "Performance..."

## Process

1. **Read the text.** Understand what it's saying.

2. **Identify AI tells.** Look for the patterns above.

3. **Remove or tighten.** Replace wordy phrases with concise alternatives. Remove filler. Use active voice. Delete over-explanation.

4. **Maintain meaning.** Don't change what the text says, just how it says it.

5. **Check tone.** Ensure the result sounds natural and human, not terse or robotic.

## Guidelines

- Be concise but not terse
- Use active voice
- Delete filler and hedging
- Assume the reader is intelligent
- Write like you would speak to a colleague
- Use contractions where natural
- Vary sentence length
- Use examples instead of abstract descriptions when possible

## Output

The same text, tightened and de-AI'd, with the same meaning but natural human phrasing.
