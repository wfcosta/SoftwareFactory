# Skill: Test-Driven Development (TDD)

**Trigger:** When fixing defects or implementing new feature behaviors.

## Operational Steps
1. **Failing Test First:**
   - Write a deterministic unit or integration test that exercises the expected behavior or bug.
2. **Observe Failure:**
   - Execute the test and verify it fails with the expected assertion error.
3. **Minimal Implementation:**
   - Write the smallest possible implementation to satisfy the test (*Laziness Protocol*).
4. **Green & Verify:**
   - Ensure the test passes cleanly alongside the existing suite without regressions.
