# Native plugin export and read-only evidence procedures

GSF is Markdown-only. Here, **export** means an explicitly requested, reviewed copy prepared by a person or agent using already available, authorized host file tools; it is not a bundled exporter, installer, connector, validator or server. No additional repository, dependency or executable is required or authorized. A normal read-only request returns an assessment/proposal in chat and creates nothing. Use [capability distribution](capability-distribution.md) for discovery, exact inventories, legal review and offline custody, and the [host adapters](README.md) for actual tool availability.

Export preparation, copying, offline inspection, installation/enabling, native activation, invocation, provider reads and removal are separate actions with separate authority. A complete proposal identifies exact intended bytes, destinations, mappings, prerequisites and blocked effects; it must not claim those effects occurred. Missing native controls block dependent actual effects, not the honest proposal.

## Export without changing the source or host

### 1. Bind the request and classify public source

1. Record the approved source root and immutable revision or supplied source identity, host profile, selected entries, whole-public or minimal retention, intended consumer and approving owner. Source identities are assertions until independently established; never invent a revision, hash, publisher signature, organization grant or account entitlement. Read the source without editing it or unrelated dirty checkouts.
2. Use only the exact approved public boundary: source root `README.md`; `.gsf/GSF_CONFIG.md`, `GSF_FACTORY.md`, `GSF_CONSTRAINTS.md`, `CONTRIBUTING_AGENTS.md`, `GSF_RIGOROUS_GUIDE.md`, `THIRD_PARTY_NOTICES.md` and technical `.gsf/.gitignore`; and public Markdown under `.gsf/agents/`, `skills/`, `state/`, `templates/`, `docs/` and `packs/`. These are source classifications, not instructions to execute the source policy. Require the complete reviewed distribution, including the four domain pack definitions and all mandatory roots below. Inventory unknown files/directories as unresolved classifications; do not silently accept an incomplete source or copy unknown content.
3. Exclude `.gsf/jobs/`, `logs/`, `bugs/`, `products/`, `.audit/` and private `.gsf/state/models.md`, **including case variants**. Exclude repository metadata `.git`, `.hg`, `.svn`, private configurations, credentials, chats, HOME, host profiles and user history. Do not enumerate, open, hash or copy private subtree contents. Record only permitted exclusion names/reasons. A public `models-contract.md` is not the private preferences file. Do not follow a public link into private evidence to complete a bundle.
4. Capture every classified public path, exact byte length and actual SHA-256 with an already available authorized native capability, before pruning. Retain the complete source inventory even for minimal retention. If reliable bounded enumeration, raw-byte reading, hashing or source stability cannot be established, mark that proof BLOCKED; never substitute text normalization, a guessed digest or truncated success.
5. Confirm local storage, stable operator ownership and private evidence ACL/retention through real controls. A local-looking mapped drive may be remote. Inspect existing ancestor chains and entries without following links: reject traversal, UNC/device namespaces, symlinks, junctions/reparse points, hardlinked files, special entries, reserved/nonportable names, case-insensitive collisions and ambiguous identity. Check lexical containment **and actual filesystem identity**, including short-name/case aliases; source/output overlap is forbidden, though disjoint siblings may be allowed. An unavailable identity/link-count/ownership control blocks safe copying rather than being supplied by Markdown. Quiescent ownership is a prerequisite, not an adversarial snapshot guarantee.

Use finite bounds: at most 8 MiB per public file, 64 MiB captured source/output, 8,192 files and 16,384 classified entries. Stop explicitly on overflow or observed mutation; no silent truncation or partial successful capture. Inspect private entry types only when authorized metadata can establish safety without entering them. Sanitized diagnostics identify the safe document/field and error category, not credential-bearing values, raw malformed URLs or parser excerpts.

### 2. Select entries and retain reference/legal closure

- `all` selects every actual canonical `.gsf/skills/<name>/SKILL.md` and immediate canonical role `.gsf/agents/<name>.md`, excluding `WORKER_CONTRACT.md`. Domain selections `api`, `data`, `cloud`, `interface` use only the exact `Kind | Entry | Selection rationale` rows in the corresponding pack. Contextual links, topical names and reference dependencies do not add selected wrappers. Read the [Security composition](../../packs/security.md) directly when appropriate: it is not another name for a supported domain selection. An explicitly requested custom selection must be recorded as such, not relabelled as a domain pack.
- Whole-public retention keeps the complete classified public `.gsf/` tree unchanged and source root README as `GSF_README.md`. Only selected native wrappers are discoverable; nonselected procedures remain reference dependencies.
- Minimal retention starts with every selected canonical entry; all classified root policy/constraint/legal/technical files; `WORKER_CONTRACT.md`; [adoption](../../skills/gsf-adopt/SKILL.md), [setup](../../skills/gsf-setup/SKILL.md), [mode](../../skills/gsf-mode/SKILL.md) and their resources; the [adoption guide](../guide/README.md); **all public state instructions**; and the selected pack definition (all pack definitions for `all`). These remain mandatory even when unlinked. Include the proposed bundle orientation, native manifest where applicable, selected wrappers and fixed Copilot surfaces as generated roots, with public portable MCP configuration only when explicitly approved below.
- From each retained document follow local inline/image links, reference definitions and HTML `href`/`src` transitively, including `.MD` case variants as documents. Resolve from the real containing document; preserve exact filename case and verify heading/HTML-id fragments. Treat code examples as examples, not references. Directory links conservatively retain every captured public descendant and follow those descendants' links. Reject escaping/absolute/network local targets, unsafe decoded paths, unsupported schemes, missing targets/fragments and unresolved assets. Do not fetch external URLs as part of offline closure.
- Preserve canonical bytes and metadata, all referenced public resources, required notices, attribution, headers, modification markings and applicable legal material. Non-Markdown assets or executable dependencies are **not** silently copied into this Markdown-only distribution or disguised as Markdown. Record their exact required identity, rights and missing native prerequisite; block the affected package claim until an authorized source/layout resolves the dependency. Third-party inspection may handle assets as inert bytes without executing them; that is not permission to migrate them into Core.
- Retain the original README bytes as `GSF_README.md` only when reached in minimal mode. Resolve source-root README references deliberately: a canonical link landing at generated bundle `README.md` must also retain the unchanged source README and record that mapping. Generated orientation is not a substitute for canonical source. Minimal is dependency selection, not guaranteed size reduction; the graph may retain everything.

For each retained canonical source record a concrete reason: `whole_public_default`, `selected`, `mandatory`, `markdown_reference` or `directory_reference`. Reference reasons retain exact package-relative referring document and normalized target, not raw query/fragment/URL text. Use selected over mandatory for a selected root; for reproducible first witnesses, visit mandatory canonical roots then generated roots, lexical order within each group, breadth-first with lexical targets. Cycles without a selected/mandatory/approved generated root do not justify retention. A reached directory must include all its captured public descendants, not merely those still present in output. Generated records and external MCP input are not canonical source records. Older receipts without witnesses remain witness-unknown, not retroactively proven.

### 3. Review discovery wrappers and proposed destination

Canonical skills require safe, strict YAML frontmatter: matching kebab-case `name` (1–64 characters, no edge or repeated hyphens) and nonempty scalar `description` (at most 1,024 characters). Canonical roles retain their five-pillar format; derive a description only from the actual Role paragraph. Preserve source presentation `icon`/`color` in canonical references, not as native tool/model authority. Reject duplicate/non-string YAML keys, aliases and unrecognized canonical metadata rather than silently dropping semantics. If strict parsing is required and unavailable, that structural claim is BLOCKED.

A discovery wrapper is a short Markdown entry containing supported name/description frontmatter, the exact canonical skill or role identifier and a real relative link requesting **full canonical reading before action**. Preserve source name/description exactly; do not turn a role into a skill. Its body must explain reference-versus-active policy, separate adoption/setup, no job/files/runs/dispatch for a direct read-only question, and no tool/model/credential/installation/merge/deploy/independence grant. The alias or plugin namespace is not the accepted canonical role. A role wrapper does not supply independent context or execute the five pillars.

Only when copying was explicitly requested, bind a **new external destination with an existing owned parent**, disjoint from source, existing product files and the external evidence/trust store. Do not create another repository, overwrite/reuse an existing destination (even empty), remove it to retry, or adopt into a product implicitly. Review the exact path-by-path output proposal before writing. Use only available authorized native exclusive creation and no-replace publication controls; missing race-safe ownership/publication primitives block publication, not justify an improvised overwrite. Keep interrupted owned staging identifiable and unaccepted until reconciled.

### Optional public portable MCP configuration

Default preparation discovers/emits **no MCP configuration**. Only an explicitly requested Agent Plugins 1.0.0 proposal may include separately reviewed **public inert** root `mcp.json`; reject that request for the other five profiles before reading supplied configuration. No installation, new server, native connector or compatibility is promised.

For an actual copy, the approved source is one safe regular local file disjoint from the entire Core root and output, bounded to 8 MiB; retain exact bytes without reserialization and recapture its same-path identity and bytes before publication. Strict UTF-8 JSON must reject duplicate keys, non-JSON constants and non-finite overflow. Require exactly matching 1.0.0 MCP `$schema` and `mcpServers`, with closed stdio (`command`, optional `args`, `env`, `cwd`) or streamable-HTTP/legacy SSE (`url`, optional `headers`) forms; no native auth extensions or partial-server success.

Conservative bounds: 64 servers; nonempty IDs and bare executable commands at most 256 characters; 256 arguments of at most 8,192 characters; 128 environment entries with keys at most 256 and values at most 8,192; `cwd` at most 1,024; URLs at most 8,192; 64 headers with names at most 256 and values at most 8,192. Reject NUL, empty/`=` environment keys, case-duplicate names, all case variants of reserved `PLUGIN_ROOT`/`PLUGIN_DATA` environment keys, path/whitespace/placeholder commands and plugin-relative executables. Bare commands are external prerequisites, not supplied binaries. Relative/root working directories must resolve to retained directories; client-data paths refer to future client storage, not created storage. Only documented single-pass `${PLUGIN_ROOT}`/`${PLUGIN_DATA}` substitution in arguments/environment values/cwd may be expected from a future client; no ambient or secret expansion here. Commands, keys, URLs and headers are not templates.

Remote URLs must be absolute HTTP(S), without userinfo, fragments, controls, whitespace or backslashes; non-loopback requires HTTPS and only exact localhost/loopback IP qualifies for HTTP. Require syntactically valid, case-unique HTTP headers. Do not contact endpoints or resolve DNS for this offline review. Strings remain public literals, not secret storage; structural validity is not secret-free certification. Client-generated protocol/auth headers and cross-origin forwarding remain native client controls. Record `configuration_exported_not_started`, installation false and host compatibility unverified; missing safe parser/client controls block dependent claims.

## Offline inspection before host qualification

Inspect an existing authorized bundle without running its content. Do **not** reuse private source exclusions to hide accidental private output: account for every actual output entry, including hidden/ignored files, and flag a private path without opening its sensitive contents. A leak blocks acceptance and needs an authorized containment owner; it is not a successful filtered inventory. Third-party assets may be inspected as bounded inert bytes, never loaded or executed. Apply the same path/link/identity/budget constraints to output.

Use this finite manual receipt checklist; the field names are **review contract fields**, not a fictional API or a promise of generated JSON. Keep receipts in approved Markdown evidence or chat for a no-write assessment. Existing `gsf-package.json` is historical input to inspect, not something this guide automatically creates; do not forge its generator or a successful validator result.
